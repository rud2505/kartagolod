Карта голодания — файлы приложения (PWA).

Как выложить бесплатно, чтобы ставить на телефон:
1. Зарегистрируйся на github.com.
2. Создай репозиторий (New repository), например kartagolod, тип Public.
3. Add file -> Upload files: загрузи index.html, manifest.json, sw.js, icon.svg.
4. Settings -> Pages -> Source: Deploy from a branch, ветка main, папка / (root). Save.
5. Через пару минут сайт будет по адресу https://ТВОЙ_ЛОГИН.github.io/kartagolod/
6. Открой его на телефоне в Chrome -> меню (три точки) -> "Добавить на главный экран".
   После этого работает как приложение, в том числе без интернета.

Записи дневника хранятся только в телефоне.
